# Note App

A note-taking application with a web frontend and server backend.

## Project Structure

- `apps/web/` - Frontend web application
- `apps/server/` - Backend server

## Getting Started

1. Navigate to the appropriate directory (`apps/web` or `apps/server`)
2. Follow the setup instructions in each directory's README

## Development

This is a monorepo setup with separate applications for web and server components.
